После установки через скрипт команда `primevpn` становится вашим центром управления.
Запустите её без аргументов, чтобы открыть интерактивное меню, либо передайте
подкоманду для разового действия.

```bash
primevpn
```

## Меню управления `primevpn`

В меню (пункты `0`–`27`) сверху отображается статус панели/Xray, а далее:

| #     | Пункт                                  | Что делает                                                |
| ----- | -------------------------------------- | --------------------------------------------------------- |
| 1     | Install                                | (Пере)установка из удалённого скрипта                     |
| 2     | Update                                 | Обновление до последнего **стабильного** релиза           |
| 3     | Update to Dev Channel (latest commit)  | Обновление до скользящей сборки `dev-latest`              |
| 4     | Update Menu                            | Обновление только скрипта меню `primevpn`                     |
| 5     | Legacy Version (Disabled)              | Установка старой upstream-версии отключена в PRIMEVPN    |
| 6     | Uninstall                              | Удаление PRIMEVPN (см. ниже)                                 |
| 7     | Reset Username & Password              | Задать новые учётные данные; при желании отключить 2FA    |
| 8     | Reset Web Base Path                    | Сгенерировать случайный базовый веб-путь                  |
| 9     | Reset Settings                         | Сброс настроек панели (ваша учётная запись сохраняется)   |
| 10    | Change Port                            | Изменить порт панели                                      |
| 11    | View Current Settings                  | Показать имя пользователя, порт, базовый веб-путь, пути к сертификатам |
| 12–14 | Start / Stop / Restart                 | Управление службой панели                                 |
| 15    | Restart Xray                           | Перезапустить только Xray-core                            |
| 16    | Check Status                           | Статус службы                                             |
| 17    | Logs Management                        | Просмотр отладочных логов / очистка логов                 |
| 18–19 | Enable / Disable Autostart             | Включить/выключить автозапуск при загрузке               |
| 20    | SSL Certificate Management             | Let's Encrypt (домен или IP), пользовательские пути, продление/отзыв |
| 21    | Cloudflare SSL Certificate             | Wildcard-сертификат через DNS-01 с помощью Cloudflare     |
| 22    | Firewall Management                    | Установка `ufw` и правила для портов                      |
| 23    | SSH Port Forwarding Management         | Привязать панель к localhost и туннелировать через SSH    |
| 24    | PostgreSQL Management                  | Установка/миграция/управление PostgreSQL                  |
| 25    | Enable BBR                             | Переключить sysctl-управление перегрузкой BBR             |
| 26    | Update Geo Files                       | Обновить данные geoip/geosite (Loyalsoldier, IR, RU)      |
| 27    | Speedtest by Ookla                     | Запустить тест скорости Ookla                             |
| 0     | Exit                                   | —                                                         |

Некоторым из этих пунктов посвящены отдельные страницы: [SSL-сертификаты](/docs/config/ssl-certificates)
(пункты 20–21), [Безопасность](/docs/operations/security) (ограничения по IP, фаервол),
[Обратный прокси](/docs/operations/reverse-proxy) и [Настройки панели](/docs/config/panel)
(TLS), а также [База данных](/docs/reference/database) (PostgreSQL).

## Подкоманды CLI

Для скриптов и быстрых действий `primevpn` также принимает подкоманду напрямую:

| Команда                    | Действие                                            |
| -------------------------- | --------------------------------------------------- |
| `primevpn start` / `stop` / `restart` | Управление службой                           |
| `primevpn restart-xray`        | Перезапустить только Xray-core                      |
| `primevpn status`              | Показать статус                                     |
| `primevpn settings`            | Показать текущие настройки                          |
| `primevpn enable` / `disable`  | Включить/выключить автозапуск при загрузке         |
| `primevpn log`                 | Вывести отладочный лог в реальном времени           |
| `primevpn update`              | Обновить до последнего стабильного релиза           |
| `primevpn update-dev`          | Обновить до скользящей сборки `dev-latest`          |
| `primevpn legacy`              | Возвращает ошибку; установка старой upstream-версии отключена |
| `primevpn update-all-geofiles` | Обновить все geo-файлы, перезапустить при изменениях |
| `primevpn migrate-db --dsn …`  | Миграция SQLite → PostgreSQL (см. [База данных](/docs/reference/database)) |
| `primevpn pgclient [ver]`      | Установить или обновить клиентские инструменты PostgreSQL |
| `primevpn install` / `uninstall` | Установка / удаление                              |

## Обновление

- **Стабильная версия:** пункт меню **2** или `primevpn update`. Повторный запуск
  установочного скрипта также обновляет панель на месте.
- **Dev-канал:** пункт меню **3** или `primevpn update-dev` — скользящая сборка
  `dev-latest` по каждому коммиту (не стабильный релиз).
- **Старые upstream-версии:** отключены в PRIMEVPN; используйте стабильный или dev-канал.

Обновление сохраняет вашу базу данных и настройки. Перед переходом на новую
мажорную версию сделайте [резервную копию](/docs/operations/backup-restore).

<Callout type="info">
  Пользователи Docker обновляются иначе — нужно скачать новый образ и пересоздать
  контейнер (`docker compose pull && docker compose up -d`), а не использовать
  команды обновления `primevpn`.
</Callout>

## Удаление

Пункт меню **6** или `primevpn uninstall`. Команда останавливает и отключает службу,
удаляет юнит службы, а также каталоги `/etc/primevpn/` и папку установки. Если панель
использовала локально установленный PostgreSQL, она предложит удалить и его
(отдельное необратимое подтверждение).

<Callout type="warn">
  Удаление стирает базу данных (`/etc/primevpn/primevpn.db`) и вашу конфигурацию.
  Сначала сделайте [резервную копию](/docs/operations/backup-restore), если она
  может вам понадобиться.
</Callout>
